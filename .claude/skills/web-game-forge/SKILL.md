# web-game-forge

ブラウザだけで動く小さなゲームを、依存なし・ビルドなしで作り、実際に動かして確認するまでを行う。

## 方針

- 既定は **ビルド不要の静的ファイル**(`index.html` + `style.css` + `main.js`)。外部CDN・ライブラリは、ユーザーが求めた場合のみ使う。
- 既定の描画は **HTML5 Canvas 2D**。UI中心のゲーム(カード、パズル等)はDOMでもよい。
- スマホ(タッチ)とPC(キーボード/マウス)の両対応にする。
- 画像・音声は外部アセットに頼らず、図形・絵文字・WebAudioで生成する。
- 不明点が結果を大きく左右する場合のみ質問する(ジャンル、操作端末など)。それ以外は妥当な既定で進め、前提を最後に報告する。

## 手順

1. **企画を固める**(3〜5行): ジャンル、コアループ、操作、勝ち負け/スコア、難易度の上がり方。
2. **構成を作る**: 下記のディレクトリ構成に沿ってファイルを作成する。
3. **実装する**: 下記のゲーム設計ルールに従う。まず「遊べる最小版」を作り、その後に演出・難易度調整を足す。
4. **動作確認する**: 下記の検証を必ず行う。確認していないことを「動作しました」と報告しない。
5. **報告する**: 遊び方、操作方法、起動方法、確認した内容、未確認事項を簡潔に伝える。

## ディレクトリ構成

```
<game-name>/
  index.html   # canvas と最小のUI(スタート/リスタート)
  style.css    # レイアウト、スマホ対応
  main.js      # ゲーム本体
  README.md    # 遊び方・起動方法(短く)
```

リポジトリ直下に単一ゲームなら直下に置いてよい。複数ゲームなら `games/<name>/`。

## ゲーム設計ルール

- **ゲームループ**: `requestAnimationFrame` + 固定タイムステップ(例: 1/60秒)で更新し、描画と更新を分離する。`dt` は上限(例: 0.05秒)でクランプし、タブ復帰時の暴走を防ぐ。
- **状態管理**: `title` / `playing` / `paused` / `gameover` の明示的なステート。リスタートで全状態が初期化されること。
- **入力**: キーボード、マウス、タッチ(`pointer` イベント推奨)を一つの入力層に集約する。`preventDefault` でスクロール/ズームを抑止する(`touch-action: none`)。
- **画面サイズ**: 論理解像度を固定し、CSSで拡縮する。`devicePixelRatio` に対応し、ぼやけを避ける。リサイズ対応する。
- **ゲームバランス**: 定数は先頭の `CONFIG` オブジェクトにまとめ、調整しやすくする。
- **保存**: ハイスコアは `localStorage`。読み書きは `try/catch` で囲む。
- **音**: WebAudioは最初のユーザー操作後に開始する。ミュート切替を用意する。
- **乱数**: 再現性が要るなら簡単なシード付きPRNGを使う。
- **品質**: 単一ファイルが肥大化したら `<script type="module">` で分割する。コメントは「なぜ」だけ書く。

## 検証(必須)

1. 構文確認: `node --check main.js`(モジュールなら `--input-type=module` 等で確認)。
2. 実行確認: ローカルサーバーを起動する(`python3 -m http.server 8000`)。
3. ブラウザ確認: プリインストールのChromium + Playwrightで開き、以下を確認する。`playwright install` は実行しない。
   - コンソールエラー/例外がない。
   - スタート → プレイ → ゲームオーバー → リスタートが通る(入力をシミュレートする)。
   - スクリーンショットを撮り、描画が崩れていないか見る。
   - モバイルviewport(例: 390x844)でも表示・操作できる。
4. 可能なら自動テスト用に、当たり判定やスコア計算などの純粋関数を分離しておく。

Playwright起動例:

```js
const { chromium } = require('playwright');
const browser = await chromium.launch({ executablePath: '/opt/pw-browsers/chromium' });
```

## 完了条件

- 追加の準備なしに `index.html` を開く(またはローカルサーバー起動)だけで遊べる。
- 上記の検証を実施し、結果を報告した。
- README に遊び方と操作方法がある。
- 変更をコミットし、指定ブランチへpushした。
