# どくキノコ大作戦

広い森にはえた **どくキノコ** を、インクの水鉄砲でうちまくってきれいにする、ブラウザのアクションゲームです。
どうぶつの森のようなやさしい森と、スプラトゥーンのようなインクのぬりあいをイメージして作りました。

インストールは不要です。`index.html` は1ファイルで完結しているので、ブラウザで開くだけで遊べます(PC・スマホどちらも対応)。

## あそびかた

- 制限時間は **3分**。**どくキノコ**をうつと得点(1本 100点、大きいキノコは 300点)。
- **日本刀**: 敵が近づくと自動で刀に持ちかえます。うつボタンを押すたびに **横なぎ → 逆なぎ → 回転斬り** の3段コンボ(押しっぱなしで続けて出る)。回転斬りは大きくふっとばし、とどめを刺すと敵は空へ飛んでいきます。敵が攻撃を **ためている最中に斬ると「カウンター」**(+50点、相手はしばらく動けない)。刀は近くの毒キノコも斬れます(草むらに隠れたものも)。
- **ダッシュ**: Shift / 右クリック(PC)、画面の左がわを2回タップ(スマホ)。一瞬だけ速く走り、その間は無敵。敵のとっしんをかわしたり、敵に飛びこんで斬ったりできます。
- 続けてうつと **コンボ** になり、スコアの倍率が上がります(最大 x3)。
- 画面のはしの **★の矢印** は金色のキノコの方向です。紫の「大発生」、「ボス」、「箱」の矢印もあります。
- 左下の **ミッション** を達成すると **タイム+12秒** と +300点。次のミッションが続けて出ます。
- うさぎやリスにさわると、しばらく **仲間になってついてきて**、近くの毒キノコに体当たりしてくれます(同時に2匹まで)。
- 時間がたつと **夕方から夜** になります。夜は毒キノコが光って見つけやすくなり、ホタルが飛びます。始まりは朝もやがかかり、木の影は太陽の向きに伸びます(夕方は長く)。
- 森は場所で植生が変わります。川や池のそばは柳と葦、山ぎわは針葉樹、ほかは広葉樹で、大木のまわりに若木が集まり、ところどころ枯れ木があります。
- 森は **毎日ちがう形** になります(日付でマップが決まる)。タイトル画面にハイスコアの上位5件が残ります。

### ステージ2「まち」

ステージ1でランクB以上を取ると、タイトルで「ステージ2 まち」を選べます。ステージ1より少しむずかしい(敵のHPと速さが少し高く、数も多い)。

- **マップ**: 碁盤の目の道路と歩道、商店や住宅のビル、公園(噴水・ベンチ)、駐車した車、街灯(夜は点く)、横断歩道。
- **敵**: どろぼう(すばやく突進し、当たると**スコアを80ぬすむ**)、ゾンビ(のろいがタフ。つかまれると痛い)、リーゼントのヤンキー(突進して蹴る)。
- **ボス**: 残り1分で **リーゼント総長**(ものすごく大きい頭)。髪をくしでとかしている間が弱点(ダメージ3倍)。
- **けいさつかん**: うさぎ・リスの役。さわるとスピードアップ、しばらく仲間になって毒キノコに体当たり。
- **武器**: 基本はピストル。箱から **ライフル**(遠くまで貫通、1発が強い)、**ショットガン**(近くで7発に広がる。ふっとばす)、**ゆうどうミサイル**、**こうげきドローン**(3台が周りを飛び、敵や毒キノコを自動で撃つ。25秒)。
- キノコ・金色キノコ・大発生・ミッション・夜は森と同じです。

### やりこみ(ゲームをまたいで残る)

- **ずかん**: 出会ったキノコ・どうぶつ・武器が登録され、「見た / 倒した」の回数が残る。
- **じっせき**: 29個の達成目標。達成すると Tシャツの色やぼうしが増える(**きせかえ**)。
- **おまもり**: スコア100点で1ポイント貯まり、6種のおまもりを買える。1つだけ付けて開始(HP+30、最初の20秒スピードアップ、武器の時間+8秒、ボスの弱点2倍、スコア+10%、仲間が2倍長く)。
- **きょうのチャレンジ**: 曜日ごとの課題(毒キノコ35本、8コンボ、など)。達成すると★。
- **2周目の森**: ランクA以上を取ると解放。敵が強く、金色キノコがよく出て、スコア1.5倍、ポイント2倍。
- HP が 0 になると終了。ゴリラ・クマ・イノシシに気をつけて!

### キノコとどうぶつ

| なまえ | はたらき |
| --- | --- |
| どくキノコ(むらさき・あか) | インクをあててきれいにすると得点。**さわって食べてしまうと、しばらく動きがのろのろ**になります。 |
| ふつうのキノコ(ちゃいろ・しろ) | さわって食べると **HPが回復**。HPがまんたんなら食べずに残しておけます。 |
| うさぎ・リス | **さわるとスピードアップ**。にげ足が速いので、ねらって追いかけよう。 |
| どくの大発生 | 30秒後から約48秒おきに、1か所に毒キノコが大量に生え、紫の汚染が広がる。**42秒以内に全部きれいにすると +1200** と花畑。間に合わないと汚染が残り、その上では足が遅くなる。敵もそこに集まる。 |
| キノコおやかた(ボス) | 残り約1分で登場する巨大な毒キノコ。胞子を飛ばして小さな毒キノコを生やし、毒の雲で足を遅くする。**かさを持ち上げた瞬間(「いまだ!」)に撃つとダメージ3倍**。倒すと +3000、周りの毒キノコも消え、タイム+10秒、ランクが1つ上がる。 |
| 武器の箱 | 12秒後から約22秒おきに落ちている。拾うとしばらく武器が変わる。**ブーメラン**(押しっぱなしで次々投げる。6個まで。キャッチすると Lv3 まで大きくなる)、**ゆうどうミサイル**(敵や毒キノコを自動で追いかけ、当たるとはじける)、**オムニショット**(四方八方に一斉に撃つ)、**虹の水てっぽう**(当てた動物が仲間になり、最後まで一緒に戦う。4匹まで)。 |
| 金色のキノコ | ときどき現れて **走ってにげる**(弾もよける)。約25秒でいなくなる。たおすと **10秒間のゴールドパワー**: 無敵、弾が敵やキノコを自動で追いかける、連射と足が速くなる、**体当たりで敵をふっとばせる**、得点2倍。 |
| イノシシ | ためてから **まっすぐとっしん**。木や岩にぶつかるとめをまわします。 |
| クマ | 近づくと **つめでなぎはらい**。タフです。 |
| ゴリラ | **ジャンプして着地**、まわりにしょうげき波。近づけばパンチ。 |

敵が攻撃する前には **赤いゾーン** がしめされます。ゾーンの外に出ればダメージをうけません。
インクを当てると敵はひるんで、いっぱいぬると逃げていきます(得点)。

### 森のなか

- **川**はわたれません。**橋**をさがそう。川のむこうには敵もついてきません。
- **草むら**には、どくキノコがかくれています。むらさきのあぶくが目印。近づくとすがたをあらわします。
- 木のかげに入ると、木が半透明になって自分が見えます。
- 右上の **ミニマップ**: むらさきの点が どくキノコ、あかい点が 敵、きいろい点が うさぎ・リス。
- 画面のはしの **むらさきの矢印** は、いちばん近いどくキノコの方向です。

## 遊ぶには

そのまま `index.html` をダブルクリック。うまく動かないブラウザでは、このフォルダでローカルサーバーを立てます。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

## つくり

画像・音声ファイルや外部ライブラリは使っていません。絵はすべて Canvas のパスで描き、効果音とBGMは WebAudio で合成しています。
キャラクターとキノコは、球の陰影(左上に光・ふちに影)と筒状の手足で立体的に見せています(`art.js` の `ball` / `tube` / `orb` / `shadeInside`)。
敵に当たった瞬間は別キャンバスに白いシルエットを描いて重ね、刀の斬撃は三日月の弧、ダッシュは水色の残像で表現します(`render.js`)。

```
index.html        遊ぶためのファイル(src/ から自動生成した1ファイル版。直接は編集しない)
src/index.html    画面(タイトル・HUD・けっか)
src/style.css     HUD やカードのデザイン
src/js/util.js    共通の計算(乱数・コンボ倍率・空間ハッシュなど。DOM なし)
src/js/config.js  ゲームバランスの数値(敵の強さ、制限時間、速度 など)
src/js/world.js   マップ生成(森: 川・池・橋・山・木・草むら。まち: Town.populate を呼ぶ)
src/js/town.js    ステージ2「まち」: 道路と建物の生成、まちの敵・ボス・警察・ドローンの絵
src/js/art.js     キャラクターや木・岩などの絵
src/js/audio.js   効果音とBGM
src/js/input.js   キーボード・マウス・タッチ入力
src/js/entities.js プレイヤー・インク弾・敵AI・キノコ・どうぶつの動き
src/js/features.js 大発生・武器・ボス・ミッション・仲間・夕夜
src/js/melee.js   日本刀: 近くの敵を自動でねらう3段コンボ、カウンター、斬撃の当たり判定と持ちかた
src/js/meta.js    ずかん・じっせき・きせかえ・おまもり・日替わりチャレンジ・2周目(localStorage に保存)
src/js/render.js  描画(地面→川→インクの跡→奥から手前の物体→効果)とミニマップ
src/js/main.js    起動・タイトル/プレイ/けっかの切りかえ・メインループ
scripts/build.js  src/ を index.html にまとめる
tests/            ルールとマップ、ビルドのテスト
```

### 変更したら

`src/` を直したら `node scripts/build.js` で `index.html` を作り直します(古いままだとテストが失敗します)。

### スマホ

- 指が使える端末では、左右のスティックと操作ガイドが自動で出ます。ピンチ拡大・スクロールは止めてあります。
- 動きが重い端末では、描画の細かさを自動で下げてコマ落ちを減らします。
- 遊んでいる間は画面が暗くならず(対応端末のみ)、ダメージをうけると振動します(Android など)。

### 調整する

遊びごこちは `js/config.js` の数字で変えられます(制限時間 `timeLimit`、プレイヤーの速さ `player.speed`、
うつ速さ `gun.rate`、敵の強さ `enemies`、敵が増えるペース `director` など)。

### テスト

```sh
node tests/logic.test.js
node tests/build.test.js
```

コンボ倍率・当たり判定まわりの計算に加えて、マップが毎回同じに作られること、橋で川の向こうに行けること、
キノコや動物がめりこまない場所に出ることなどを確認します。

URL のおわりに `?debug` をつけると、ブラウザのコンソールから `__kinoko` でゲームの状態をのぞけます(動作確認用)。
